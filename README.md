# ZADDR // TRIBUTE — "Nice to not meet you."

> *"Your name is public. Everything else is shielded by default. 2,800 faces on Zcash."*

A dark cinematic cypherpunk art installation and 12-frame dissolution tribute created for **[ZADDR](https://zaddr.net)** on the [Zcash](https://z.cash) Orchard shielded pool.

---

## 🛡️ Ethos & Felsefe

1. **The 12-Frame Dissolution Continuum**:
   - *"Every face is a twelve-frame sequence — the drawing dissolving into its shielded state. That dissolve is the whole idea of the project in one loop. The art is public. The ownership is not."*
2. **Client-Side ZK Cryptography**:
   - Zero keys leaving the user device. Local WebAssembly proving in the browser tab.
3. **Sovereign Identity**:
   - 178-character shielded addresses mapped to human-readable names.

---

## ⚡ Features

- **Atmospheric Sub-Bass Cypherpunk Drone**: Generated dynamically in-browser via the Web Audio API.
- **Interactive Orchard Shielding Lens**: Real-time cursor reticle triggering the 12-frame pixel dissolution and floating quantum ash particles.
- **Tribute Faces**: Hand-crafted 32x32 pixel faces (#0112 The Dissident, #0842 The Shadow, #1984 The Punk).
- **10-Second Teaser Video Recorder**: Built-in 60fps canvas recorder generating ready-to-tweet `.webm` cinematic teaser trailers for X (Twitter).

## 🚀 How to Run Locally

Simply clone and open `index.html` in any modern web browser:

```bash
git clone https://github.com/mrrobotcrypto/zaddr.git
cd zaddr
# Run any static server (or double click index.html)
python -m http.server 3000
```

Visit: `http://localhost:3000`
